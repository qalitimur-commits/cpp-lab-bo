# СРС №2 — Модернизация бота лаборанта ИКТ

## Описание
В код бота добавлены три расчетно-правовых модуля с сохранением функционала из СРС №1.

### Модули:
1. **Учет рабочего времени:** Валидация часов с блокирующим циклом при некорректном вводе.
2. **Дисциплинарные взыскания:** Оформление инцидента и выписка из устава ВУЗа.
3. **Протокол реагирования на саботаж:** Пошаговый вывод с задержками времени (`std::this_thread::sleep_for`).

## Запуск
```bash
g++ main.cpp -o bot -pthread && ./bot
